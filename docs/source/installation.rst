=================================
Installation
=================================

Dir-handler is currently installable from source. Clone the repository
from the `GitHub Page <https://github.com/Applied-Materials-Technology/dir-handler>`_

You may wish to use a virtual environment e.g. with `venv`

.. tab-set::
   
   .. tab-item:: pip

      .. code-block:: bash

        python -m venv dirhandler-env
        source dirhandler-env/bin/activate

Go to base directory of dir-handler and enter the following command:

.. tab-set::
   
   .. tab-item:: pip

      .. code-block:: bash

        pip install -e .
